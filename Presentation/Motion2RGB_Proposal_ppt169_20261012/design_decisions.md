# 设计决策

用户已指定直接生成，确认由当前作者代理决策。使用 Default Generate 的委托分支，不创建虚构的 UI 确认记录。

Stage 1：中文，VR 课程教师与同学，2026-10-15 现场 5 分钟开题，16:9，7 页，自由设计。目标是解释视觉采集差异、真实技术链路、当前原型和后续可验证的工作。会后可继续编辑。

Stage 2 三个完整方向：

1. 实证技术报告：封面真实双视图，背景对照，运动因果链，双分支架构，模型公式，主截图，必做与可选工作。白底、大字、青蓝方向线、完整截图，少量深蓝强调。真实图像原始色彩，无纹理，无人工生成视觉。首选，符合教室投影与技术核查需求。
2. 连续系统讲解：以同一条四步主链跨页保持位置，每页展开当前模块，最后回到全系统。浅灰底、蓝色区域边界，截图分阶段嵌入。原始图片，无材质效果。可减少认知切换，但会压缩结果页视觉面积。
3. Demo 主导汇报：双视图开场，先看 Demo，再倒推动机和模型，最后总结工作。白底、大面积截图、窄说明边栏，原始视觉，无额外渲染。画面冲击较强，但不采用，因为用户的七页顺序更适合开题逻辑。

最终选择方向 1。正文 28 px，标题 40 px，说明 22 px，页脚 14 px；Microsoft YaHei 与 Arial，数学 Cambria Math。Speaker Notes 开启，总时长 300 秒；Custom Animations 与 Narration Audio 关闭；continuous，brief，不进入额外规范确认。
