# 真实曝光标定：采集指南

目标：拿到**一对**同一场景的"清晰 / 运动模糊"图，从而反解出相机的真实快门时间 `T`，
再与引擎的 `Exposure Proxy` 对齐，把"heuristic"变成"calibrated"。

## 为什么必须是一对

盲反卷积在普通场景上不可行：模糊量随深度变化，图上没有统一的周期。
**一块正对相机的平面纹理**只有一个深度，模糊就是均匀的，倒谱法可以稳定测出长度。
有清晰图作对照，还能把光学/抗锯齿造成的固有边缘宽度分离出去。

## 拍什么

- **平面纹理板**：A3 打印，哑光纸。内容是黑白条纹/棋盘 + 一些彩色块，细节从 2 mm 到 3 cm 都有；
  贴在硬纸板/亚克力上保证平整。
- **背景**：板子后面是纯色墙面，避免干扰。
- **光照**：稳定、均匀，不要有闪烁（关掉节能灯，用直流台灯或白天室内）。
- **距离**：1.5–3 m，让板子占画面 60–80%。

## 怎么动（二选一）

### 方案 1：直线平移（推荐，公式最简单）

让**板子**沿平行于像面的方向匀速移动，相机固定。

- 用一个匀速小车、传送带、或电钻+丝杠;
- 或者反过来：相机装在滑轨/小车上横向移动，板子固定。

要求：速度恒定（±10%），运动方向尽量平行于像面（不要有前后分量）。

### 方案 2：相机原地匀速转（次选）

相机装在三脚架上，云台匀速水平摇，正对远处一面**平板墙**（距离 > 3 m，墙面近似平面）。

要求：摇速恒定。可以用手机放一个 60 BPM 的节拍器，每拍转固定角度。

## 拍两（多）张

同一运动过程中连续拍：

| 张 | 快门 | 用途 |
| --- | --- | --- |
| 清晰 | 1/2000 s 或更短 | 作为光学基准 |
| 模糊 1 | 1/60 s | 轻度模糊 |
| 模糊 2 | 1/30 s | 中度模糊 |
| 模糊 3 | 1/15 s | 重度模糊 |

其余参数（ISO、光圈、对焦、白平衡）**全部锁定为手动**，三张保持一致。

> 手机注意：不要用自动 HDR / 夜景模式 / 人像模式，这些会做多帧合成和锐化。
> 有专业模式（Pro）的话锁 ISO、锁对焦、手动快门；没有的话借一台相机。
> 另外尽量别用滚动快门拍高速运动，会引入斜切。

## 必须记录的信息

| 项 | 怎么来 | 用途 |
| --- | --- | --- |
| 每张的快门时间 | EXIF（`ExposureTime`） | 校验结果 |
| 焦距 | EXIF（`FocalLength`，mm） | 算 `fx` |
| 传感器宽度 | 查机型规格（如全画幅 36 mm、APS-C 23.5 mm、手机约 7 mm） | 算 `fx` |
| 图像宽度 | 像素 | 算 `fx` |
| 板子到相机的距离 `z` | 卷尺，米 | 直线模型 |
| 运动速度 `v` | 见下 | 直线模型 |
| 或者摇摄角速度 `ω` | 见下 | 旋转模型 |

**算 fx（像素）**：`fx = 焦距(mm) / 传感器宽度(mm) × 图像宽度(px)`

**测速度 `v`**：在板子旁边放一把尺子，用同一台相机拍一段**短快门视频**（≥ 60 fps），
数出板子在相邻帧间移动了多少像素，再用 `v = Δpx · z / (fx · dt)` 反算。或者直接读小车的
里程/转速。

**测角速度 `ω`**：拍一段短快门视频，用视频里两个固定点的位移估出每帧转角，除以帧间隔。

## 拍完怎么跑

```bash
python calibrate_pair.py \
  --sharp  sharp_1_2000.png \
  --blurred blur_1_30.png \
  --fx 1200 --distance 2.0 --speed 1.2 \
  --angle 0            # 模糊方向（水平为 0°；竖直为 90°）
  --out report.json
```

输出会给出：

- 倒谱估的模糊长度（px）；
- 反解的有效曝光 `T`（ms）；
- 与 EXIF 里的快门时间对比 —— 两者接近说明模型标定成功。

旋转模型：

```bash
python calibrate_pair.py --sharp a.png --blurred b.png --fx 1200 --omega 0.8
```

## 验收标准

1. 三张模糊图各自反解出 `T`，与 EXIF 快门的比值应彼此接近（离散度 < 20%）；
2. 该比值就是引擎 `Exposure Proxy` 到真实快门的换算系数；
3. 把系数写回 `meta.json` 的 `exposure_seconds`，重跑 `degrade.py`，TUM 段的模糊量应与真实帧一致。

## 常见坑

- **板子不平面**：贴墙时中间鼓起来，深度就不唯一了，倒谱峰会变宽；
- **运动不匀速**：起步/刹车段不要用，掐中间匀速那一段；
- **自动对焦漂移**：锁手动对焦，否则清晰度变化会被误判成模糊；
- **画面过曝**：长快门容易过曝，锁 ISO 后适当收光圈或减光；
- **JPEG 压缩**：尽量存 PNG/TIFF，JPEG 的块效应会在倒谱里制造假峰。
